# Politica de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades, datos personales, credenciales ni pruebas de concepto explotables en un issue publico.

Envia el reporte a `soporte@proxima.do` con el asunto `Reporte de seguridad`. Incluye:

- descripcion y posible impacto;
- pasos minimos para reproducirlo;
- rutas o componentes afectados;
- cualquier mitigacion sugerida.

No incluyas datos reales de usuarios. Proxima confirmara la recepcion y coordinara de forma privada la validacion y correccion del hallazgo.

## Alcance

Se aceptan reportes sobre la aplicacion web, autenticacion, autorizacion, operaciones financieras, integraciones y exposicion de datos. Las pruebas deben evitar degradar el servicio, acceder a cuentas ajenas o modificar datos de produccion.
